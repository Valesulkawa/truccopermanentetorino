# Trucco Permanente Torino - Single Page

Progetto React + Vite + Tailwind già pronto da aprire in Codex/Replit/locale.

## Avvio locale

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

La cartella di output sarà `dist/`.

## Immagini

Le immagini sono già incluse in:

```txt
public/images/
```

Nel codice vengono richiamate così:

```js
/images/sopracciglia.jpg
/images/labbra.jpg
/images/occhi.jpg
/images/correzione.jpg
/images/areola.jpg
/images/trico.jpg
/images/rosanna-hero.jpg
```

## Note

- Il sito è single page e mobile-first.
- La CTA principale apre WhatsApp.
- Il menu mobile è dentro la barra bianca superiore.
- La sezione trattamenti è accordion su mobile e griglia su desktop.
